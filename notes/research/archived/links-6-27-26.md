Here are the direct URLs to the empirical studies and research papers supporting the testing strategies discussed:
Property-Based vs. Example-Based Testing
Study: "Understanding the Characteristics of LLM-Generated Property-Based Testing" (Tanaka et al., 2025)
URL: https://arxiv.org/abs/2510.25297
Key Finding: Hybrid approach (PBT + EBT) achieves 81.25% bug detection vs. 68.75% for either alone; PBT excels at performance/edge cases, EBT at specific boundaries. 
Mutation Testing & Software Evolution
Study: "Evaluating LLM-Based Test Generation Under Software Evolution" (2026)
URL: https://arxiv.org/abs/2603.23443
Key Finding: 99% of failing LLM-generated tests on mutated code were actually passing on the original code, proving LLMs memorize patterns rather than verify logic. 
Study: "A Comprehensive Study on Large Language Models for Mutation Testing" (Wang et al., 2026)
URL: https://arxiv.org/abs/2406.09843
Key Finding: LLM-generated mutants achieve 1.75× improvement in real bug detection over traditional tools, despite higher non-compilability rates. 
Paper: "Mutation-Guided Unit Test Generation with a Large Language Model" (MUTGEN, 2026)
URL: https://arxiv.org/abs/2506.02954
Mocking Strategies & ASTER
Paper: "ASTER: Natural and multi-language unit test generation with LLMs" (IBM Research, ICSE 2025 Distinguished Paper)
URL: https://research.ibm.com/blog/aster-llm-unit-testing
Key Finding: Static analysis-guided mocking outperforms EvoSuite by 26.4% in line coverage for Java EE projects; developers prefer ASTER tests over conventional auto-generated tests. 
Preprint: "Multi-language Unit Test Generation using LLMs" (Detailed ASTER methodology)
URL: https://arxiv.org/abs/2409.03093
Prompting Strategies (Sequential & RCI)
Study: "Impact of code context and prompting strategies on automated unit test generation" (Journal of Systems and Software, July 2026)
URL: https://www.sciencedirect.com/science/article/abs/pii/S0164121226000683
Key Finding: Sequential multi-turn prompting achieves 96.3% branch coverage and 57% mutation score; including docstrings improves coverage by ~19.7pp. 
Study: "Prompting Techniques for Secure Code Generation: A Systematic Investigation" (Tony et al., 2024/2025)
URL: https://arxiv.org/abs/2407.07064
Key Finding: Recursive Criticism and Improvement (RCI) reduces vulnerability density by 77.5% compared to zero-shot prompting. 
Summary: "Secure Code Generation Methods" (Emergent Mind)
URL: https://www.emergentmind.com/topics/secure-code-generation-methods
