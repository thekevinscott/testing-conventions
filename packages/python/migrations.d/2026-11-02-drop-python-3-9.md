### The Python package requires Python 3.10+

**Summary**

`testing-conventions` on PyPI declares `requires-python = ">=3.10"`. Python 3.9 reached end of
life in October 2025, and GitHub's `ubuntu-latest` image (Ubuntu 26.04) has no 3.9 build, so the
package can no longer be tested there. CI covers 3.10 through 3.13.

**Required changes**

A consumer running on Python 3.9 moves its test environment to 3.10 or newer. On 3.9, pip
resolves to the last release that declared `>=3.9` instead of this one.

**Deprecations removed**

_None._

**Behavior changes without code changes**

_None_ on 3.10 and newer.

**Verification**

```console
$ python --version
Python 3.10.x
$ pip install testing-conventions
$ testing-conventions --version
```
